<h2 id="features">✨ Features</h2>

- Menu de navegação com acesso à página de login
- Cabeçalho com animação gradiente e chamada para assinatura
- Cards com os planos de assinatura (Mobile e Multitelas) animados
- Seção com os canais/conteúdos disponíveis na plataforma (HBO, Max Originals, DC, Warner Bros, Cartoon Network, UEFA Champions League)
- Página de login (`signIn.html`) com formulário e validação visual de campos inválidos
- Rodapé com links institucionais e redes sociais
- UI Responsiva

*As features são visuais, não possuindo integração com nenhuma API. O intuito do projeto é reproduzir a interface do site original, com algumas modificações.*

<h2 id="topics">📦 Temas abordados</h2>

Recursos CSS presentes no projeto:

- Fundamentos do CSS
- Grid Layout
- Flexbox
- Responsividade
- Pseudo-elementos
- Pseudo-classes
- Transformações 2D e 3D
- Transições e animações
- Tratamento de campos inválidos no formulário

<h2 id="challenges">🏆 Desafio</h2>

O desafio proposto foi reproduzir a página inicial e a tela de login do HBO Max apenas com **HTML e CSS puros**, sem frameworks nem bibliotecas, priorizando fidelidade visual ao layout, às animações de gradiente e à responsividade do site original.

<h2 id="run">🚀 Como executar</h2>

Não há dependências ou build — é um site estático. Basta abrir o `index.html` diretamente no navegador ou servir a pasta com um servidor estático simples, por exemplo:

```bash
npx serve .
# ou
python3 -m http.server
```
